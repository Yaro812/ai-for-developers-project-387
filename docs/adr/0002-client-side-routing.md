# У каждой страницы фронтенда свой URL

Страницы фронтенда переключаются через `react-router`, и у каждой есть собственный путь: `/` — главная, `/book` — каталог типов встреч. Переключение через состояние React отвергнуто: на страницу нельзя дать ссылку, не работает кнопка «назад» и прямой заход.

## Последствия

Сервер, который раздаёт собранный фронтенд в Docker-образе, должен отвечать `index.html` на любой путь, не совпавший с файлом или API, иначе прямой заход на `/book` вернёт 404.
