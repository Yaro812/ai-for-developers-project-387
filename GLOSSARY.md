# Календарь звонков

Сервис, через который гость бронирует звонок с владельцем календаря. Термины пишутся по-русски в тикетах и интерфейсе; имя в скобках — то же понятие в коде.

## Участники

**Владелец** (`Owner`):
Единственный человек, чьё время бронируют; задан заранее и не регистрируется.
_Avoid_: Хост, администратор, пользователь

**Гость** (`Guest`):
Человек, который бронирует звонок с владельцем без регистрации.
_Avoid_: Клиент, посетитель, пользователь

## Бронирование

**Тип встречи** (`EventType`):
Вид звонка, который предлагает владелец: id в адресе страницы бронирования, название, необязательное описание и длительность.
_Avoid_: Ссылка, услуга, шаблон встречи

**Бронирование** (`Booking`):
Занятый гостем интервал времени для конкретного типа встречи, с именем и email гостя.
_Avoid_: Запись (глагол «записаться» допустим), встреча (вне «тип встречи»), резерв

**Пояс владельца** (`OwnerTimeZone`):
Часовой пояс, в котором заданы часы работы и границы дней и в котором гость видит время слотов.
_Avoid_: Таймзона, местное время, пояс гостя

**Часы работы** (`WorkingHours`):
Дни недели и интервал дня в поясе владельца, в которые владелец принимает звонки.
_Avoid_: Рабочее время, расписание, доступность

**Текущий момент** (`Now`):
Момент по часам сервера, от которого отсчитываются окно бронирования, слоты и предстоящие бронирования; часы браузера гостя его не задают.
_Avoid_: Текущее время, время браузера, сейчас

**Окно бронирования** (`BookingWindow`):
Сегодняшний и 13 следующих календарных дней в поясе владельца, в которые гость может выбрать день для бронирования; сдвигается вместе с текущей датой.
_Avoid_: Окно записи, период, горизонт

**Шаг слотов** (`SlotStep`):
Общий для всех типов встреч промежуток между началами соседних слотов, отсчитанный от начала часов работы.
_Avoid_: Интервал, гранулярность, сетка

**Слот** (`Slot`):
Интервал длительностью в тип встречи, с которого может начаться бронирование: начинается на шаге слотов позже текущего момента и целиком лежит в часах работы одного дня окна бронирования. Слот **свободен**, если не пересекается ни с одним бронированием.
_Avoid_: Окно, ячейка, свободное время

**Конфликт бронирования** (`BookingConflict`):
Попытка забронировать интервал, который пересекается с существующим бронированием.
_Avoid_: Коллизия, двойное бронирование, наложение

**Недоступное время** (`UnavailableTime`):
Попытка забронировать интервал, который не является слотом.
_Avoid_: Занятое время, неверный слот

## Страницы

**Каталог типов встреч** (`EventTypeCatalog`):
Страница, на которой гость выбирает тип встречи, чтобы начать бронирование.
_Avoid_: Страница записи, список услуг

**Страница бронирования** (`BookingPage`):
Страница типа встречи, на которой гость выбирает день и слот и подтверждает бронирование.
_Avoid_: Страница записи, форма бронирования

**Новый тип встречи** (`NewEventType`):
Страница владельца, на которой он создаёт тип встречи.
_Avoid_: Настройки, редактор типа встречи, создание ссылки

**Предстоящие бронирования** (`UpcomingBookings`):
Страница владельца со всеми ещё не закончившимися бронированиями всех типов встреч.
_Avoid_: Предстоящие встречи, мои записи, расписание
